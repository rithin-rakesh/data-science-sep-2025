# Python Practice Exercises — September 2025

A small learning repository with introductory Python scripts and placeholder text files.

## Contents

- `work.py` — simple addition and subtraction functions.
- `work1.py` — addition function and basic variables.
- `work2.py` — addition of three numbers and console output.
- `data.txt`, `data1.txt`, `data2.txt`, `data3.txt` — currently empty placeholder files.

## Run

**Requirement:** Python 3.

```bash
git clone https://github.com/rithin-rakesh/data-science-sep-2025.git
cd data-science-sep-2025
python work2.py
```

The scripts are independent practice exercises rather than a complete data-science application. No third-party packages are required for the current code.
